TYTUL: Budowa Agenta AI do automatyzacji Marketplace (400 SKU)
BUDZET: Do negocjacji

OPIS:
Opis Budowa Agenta AI do automatyzacji Marketplace (400 SKU na początek) Cel projektu: Stworzenie autonomicznego agenta AI, który będzie zarządzał asortymentem (400 produktów) na platformach Allegro i Amazon. System ma pilnować jakości ofert, monitorować konkurencję i automatyzować proces listowania. Kluczowe moduły do wdrożenia: Monitoringu & Dynamic Pricing: Agent ma sprawdzać ceny konkurencji przez API i sugerować zmiany (lub wprowadzać je w oparciu o ustalone reguły marżowe). Quality Assurance (AI Editor): Automatyczna optymalizacja opisów, tytułów i parametrów pod SEO/A+ Content przy użyciu LLM (np. GPT-4o lub Gemini Pro). Inventory Sync: Integracja z bazą danych (np. Google Sheets / Airtable) i synchronizacja stanów przez API (BaseLinker lub bezpośrednie API marketplace'ów). Wymagane funkcje: Wymagane kompetencje: • Biegłość w pracy z API Allegro oraz Amazon Selling Partner API (SP-API). • Doświadczenie w budowaniu agentów AI (frameworki typu CrewAI, LangChain lub platformy n8n / Make.com). • Umiejętność pracy z LLM (prompt engineering, przetwarzanie strukturalne danych). • Znajomość Python lub Node.js (jeśli rozwiązanie ma być customowe). Zadanie dla kandydata: Proszę o krótkie przedstawienie propozycji architektury (np. czy sugerujesz budowę w n8n, czy czysty Python) oraz szacunkowy koszt wdrożenia i utrzymania (koszty tokenów API).
