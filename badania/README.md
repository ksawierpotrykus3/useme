# badania/ — dane i analizy (NIE dokumentacja)

Ten folder to centrum danych. Zasada PRISTINE: surowe dane z jawnym N + hipoteza + pomysl. Zero "gotowych rozwiazan" i licznikow "na dzis".

## Struktura
| Folder | Co zawiera |
|---|---|
| `baza/` | Surowa baza zlecen obu kont (JSON). Jedno zrodlo prawdy o zleceniach. |
| `analizy/` | Analizy empiryczne, typologie klientow, technologie, case studies, atomic ammo |
| `audyt_100/` | Testy ofert, benchmarki sedziow AI, raporty |
| `LICZNIKI.md` | Definicja, czym sa rozne N uzywane w badaniach |

## Zasady
1. Kazdy raport z naglowkiem: N, charakter (fakt/hipoteza/poszlaka), data.
2. N < 15 = poszlaka. N = 1-4 = anegdota.
3. Nie mieszaj DANYCH z POMYSLEM i ZMIANA w jednym akapicie.
4. Liczniki zmieniaja sie codziennie — trzymaj je w LICZNIKI.md, nie w kazdym raporcie.
