# Typ: Tradycyjne MŚP / ERP / Przemysł

> Źródło: typologia główna (klient_01) + worek B. Oczyszczone z fikcji (kubek z logiem, monologi rodzinne).

## Kim jest
Właściciel firmy produkcyjnej, handlowej lub usługowej (8–80 osób). Używa systemu ERP: Subiekt, Enova365, Comarch Optima, Wapro, Symfonia, TopSolid. Często syn założyciela. Pracuje dużo, ręcznie, nad Excelem. System zna na poziomie operacyjnym, ale nie programistycznym.

## Co realnie go boli (obserwowalne)
- Pomyłki magazynowe: towar wydany bez dokumentu, niezgodności przy inwentaryzacji.
- Ryzyko kontroli US/KSeF, gdy faktury nie zgadzają się z magazynem.
- Zależność od jednej osoby, która „ogarnia system" — jeśli odejdzie, firma staje.
- Ręczna kompletacja (WZ/PZ) i powtarzalne klepanie danych.
- Brak kontroli nad przepływem danych między działami.

## Rozróżnienie amator / profesjonalista
- **Amator:** „zrobię skrypt".
- **Profesjonalista:** „rozumiem, że komplet na WZ nie idzie automatycznie i magazynier klepie ręcznie — to źródło błędów inwentaryzacyjnych".

## Zasada nadrzędna
Ten człowiek nie kupuje kodu. Kupuje spokój, pewność i kontrolę nad firmą, która jest jego życiem.

## Słownik naturalny
inwentaryzacja, WZ/PZ, kompletacja, MM, KSeF, stan magazynowy, integracja Subiekt–IdoSell, API Insert, baza SQL Enova, BOM, zlecenie produkcyjne.

## Słownik — natychmiast odstrasza
„transformacja cyfrowa", „end-to-end", „scalable solution", „cloud-native", „synergia", „roadmapa", „stakeholder", „value proposition".

## Jak uzasadnić cenę
Kosztem błędu, nie stawką godzinową. „Jeśli zostanie jak jest, przy inwentaryzacji różnica może wynieść X zł".

## Rozbudowane case'y (dowody)
OXYGEN (Subiekt nexo, WZ z kompletów), ENERZON (Anteeo/Base/IdoSell), Wiktoria Iwanow (TopSolid, meble), Centrum Budowlane Kołcz (Enova365 + KSeF).

## Modyfikatory (nakładki)
- **+Rescue** — po nieudanym wdrożeniu. Wtedy: etapowanie, „nie wiem, muszę zobaczyć".
- **+Wymagający ekspert** — gdy precyzyjnie definiuje deliverable.

## Demarkacje — kiedy odpuścić
- Firma ma własny dział IT, który to ogarnie.
- System nieznany i brak możliwości rozpoznania.
- Problem czysto techniczny bez kontekstu operacyjnego.
