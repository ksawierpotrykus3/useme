# Typologia klientów v2 — scalona

> Nowa, scalona wersja typologii. Powstała z połączenia typologii głównej (`badania/analizy/typy_klientow/`) i worka B (`_odzyskane/wiedza_biznesowa/`), oczyszczona z błędów wykrytych przez 4 niezależne audyty krytyczne.

## Struktura
Każdy typ = osobny folder z dwoma plikami:
- `opis.md` — kim jest, co boli, słownik, modyfikatory, demarkacje
- `taktyki.md` — dopasowane taktyki + czego unikać + CTA

## Co zmieniono względem oryginału (naprawa słabych stron)
1. **Usunięto fikcję narracyjną** — kubki, sypialnie, monologi, „Polska B".
2. **Usunięto pseudopsychologię** — „trauma", „impostor syndrome", rzutowanie motywów.
3. **Rozstrzygnięto sprzeczność call/async** — CTA = pytanie techniczne; call tylko przez Useme po domknięciu zakresu.
4. **Rozstrzygnięto cena/diagnoza** — mały zakres = cena od razu; duży/niejasny = płatny audyt.
5. **Dodano próg opłacalności** — odmów, gdy budżet poniżej progu.
6. **Dodano klauzulę poufności** — case'e tylko z anonimizacją/zgodą.
7. **Usunięto manipulację** — testy lojalności, „zaklęcia", gra na traumie.
8. **Usunięto formułki „TEORIA robocza / Track 0%"** — były słabością, nie treścią.
9. **Scalono nakładające się typy** — 3 profile „wymagającego" w jeden typ z 3 wariantami.

## Uwaga o dowodach
Oryginalne materiały miały 0 potwierdzonych testów (`potwierdzone.md`, `track.md` puste). Dlatego te pliki opisują **hipotezy i taktyki do przetestowania**, nie sprawdzone reguły. Nie traktuj żadnej taktyki jako pewnika, dopóki nie zostanie przetestowana na żywym zleceniu.
