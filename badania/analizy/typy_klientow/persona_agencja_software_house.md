# PERSONA: AGENCJA / SOFTWARE HOUSE (PODWYKONAWSTWO)

## Profil Klienta
PM, Tech Lead lub właściciel software house'u szukający wsparcia dla swojego zespołu na zlecenie klienta końcowego.

## Cechy i Styl Pracy
- Szybka decyzyjność (średnio 9.5 wiadomości na priv).
- Zero marketingu – sprawdzają kompetencje, pytają o repozytorium, code review, stawkę B2B.

## Jak Rozmawiać
- Czysty konkret architektoniczny, podanie dostępności, transparentność technologiczna.
