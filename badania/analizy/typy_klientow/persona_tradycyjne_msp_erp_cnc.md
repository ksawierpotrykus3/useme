# PERSONA: TRADYCYJNE MŚP / PRZEMYSŁ / ERP / CNC

## Profil Klienta
Właściciel fabryki, hurtowni, zakładu produkcyjnego. Zmaga się z fizycznymi maszynami lub ociężałym ERP (Subiekt Sfera, Enova365, Wapro, TopSolid).

## Potencjał Finansowy
- Wysokie budżety (2 800 – 16 000 PLN).
- Znikoma konkurencja: 95% freelancerów z Useme potrafi robić tylko proste strony i odpada przy API CAD lub Sferze SQL.

## Jak Wygrywać
- Partnerski ton inżynierski.
- Wskazanie warstwy translacji danych między systemami oraz zabezpieczenie bazy przed deadlockami.
